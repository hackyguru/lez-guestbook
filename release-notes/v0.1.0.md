**LEZ Guestbook v0.1.0**: a guestbook on the Logos Execution Zone testnet that everyone shares.

> [!WARNING]
> **Unofficial, experimental, testnet only.** Not an official Logos module. It talks to the public LEZ v0.3 testnet, whose LGO has no value and which can be reset.

### Packages (Basecamp 0.2.3)

| File | What it is |
|---|---|
| `logos-guestbook_core-module-lib.lgx` | `guestbook_core` core module (embedded LEZ wallet), macOS arm64 + Linux x86_64 |
| `logos-guestbook-module.lgx` | `guestbook` UI, macOS arm64 + Linux x86_64 |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from **Modules → Install LGX Package**.

### What's in it
- A guestbook program deployed on the LEZ v0.3 testnet at `Edc6RDHB6bjCUfseKfff7jkhEwWqDHuBieWpE2YiyHq`. Every install reads and signs the same book.
- Each entry is signed by its author's account and stored on chain. Gas comes from the testnet faucet automatically.
- `verify.sh` reads the newest entries straight from the sequencer.
