**LEZ Guestbook v0.1.1**: points at the guestbook program redeployed after the LEZ testnet reset.

> [!WARNING]
> **Unofficial, experimental, testnet only.** Not an official Logos module. It talks to the public LEZ v0.3 testnet, whose LGO has no value and which can be reset.

### Changes
- The testnet reset wiped the v0.1.0 deployment. The same `guestbook.bin` (image id `00e8aa77…`) is redeployed at `9g3esWieKeD886uvSKdoH7AntwoAMiiTKWinZXMoYzz5`, and the core now uses that address by default. The book starts empty again. Its header account is `C4qKMDDbsQE3pGBbJBaM3r5LTa7rxbAP6vwGfnLR1ewQ`.
- **Details → Use a different deployment** now keeps what you type or paste. The field was bound to the module's state, which the UI refreshes every second, so each refresh cleared it.
- `verify.sh` and the README point at the new deployment, and `verify.sh` prints "1 signature" rather than "1 signatures".
